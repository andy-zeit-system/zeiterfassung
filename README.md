# Zeiterfassung

Zeiterfassung für PC und Handy: Arbeitszeit, Urlaub, Krankheit, Feiertage (Niedersachsen), Überstunden und Lohnübersicht.

- **App:** https://andy-zeit-system.github.io/zeiterfassung/
- **Daten:** Supabase (Anmeldung per E-Mail/Passwort, jede Person sieht nur ihre eigenen Daten – Row Level Security)
- **Datenbank-Schema:** `supabase/schema.sql`

Dieses Repository enthält **nur den Programmcode**, keine Arbeitsdaten.
Der Schlüssel in `index.html` ist der öffentliche „Publishable key“ – er ist ohne Anmeldung nutzlos.

Auf dem Handy: Seite im Browser öffnen → „Zum Startbildschirm hinzufügen“.
